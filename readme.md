# 📌 项目介绍
阿米诺斯人专用的翻译器，更方便，更快捷。

# 使用说明
1. 需要安装FFmpeg
2. 项目并没有经历太多的测试，如果遇到bug请反馈，看到就会回复
3. 建议使用管理员权限启动

# 正确使用方式
1. run check.py
2. run test.py
3. run main.py
