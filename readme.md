# 📌 项目介绍
阿米诺斯人专用的翻译器，更方便，更快捷。

# 使用说明
1. 需要安装FFmpeg
2. 项目并没有经历太多的测试，如果遇到bug请反馈，看到就会回复
3. 建议使用管理员权限启动

# 使用方式
1. 前期准备：
   
   a. 安装Anaconda

   b. 配置虚拟环境（python=3.10.20）
2. cd ./Aminoac
3. run check.py 查看是否缺少依赖库
4. run test.py  测试代码
5. run main.py  运行主程序
